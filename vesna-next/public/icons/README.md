# PWA Icons

This directory should contain the following icon files for the PWA:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

All icons should be square PNG images with a transparent background.
The main logo/branding should be centered and occupy about 80% of the space.

For quick testing, you can use a service like:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

The theme color for the app is #131312 (dark background).
